## 变量
### 变量命名规则：
+ 变量名以 $ 符号开始，后面跟着变量名
+ 变量名必须以字母或者下划线字符开始
+ 变量名只能包含字母数字字符下划线
+ 变量名不能有空格
+ 变量名是区分大小写的

> php语句和变量都是区分大小写的
>

```php
<?php
$age = 18;
$name = 'szp'
?>
```



### 变量的作用域：
变量的作用域是脚本中变量可被使用（引用）的部分

PHP有四种不同的变量作用域：

+ lcoal
+ global
+ static
+ parameter

#### 局部和全局作用域（local、global）
> **<font style="color:#DF2A3F;">在所有函数外部定义的变量，拥有全局作用域</font>**
>

除了函数外，全局变量可以被脚本中的任何部分访问，要在一个函数中访问一个全局变量，需要使用global关键字

```php
<?php
// 全局变量
$name = 'szp';

function myTest(){
  global $name; // 声明使用全局变量
  echo $name;

  // 或者通过$GLOBALS超全局数组访问
  echo $GLOBALS['name'];

  // 修改全局变量
  $GLOBALS['name'] = 'Tom';
}
myTest()

echo $name; // Tom
?>
```

<font style="background-color:#FBDE28;">PHP将所有全局变量存储在一个名为$GLOBALS的数组中，这个数组可以在函数内部访问，也可以直接用来更新全局变量的值</font>

在php函数内部声明的变量是局部变量，仅能在函数内部访问：

```php
function myTest(){
  $age = 10; // 局部变量
  echo $age;
}
```

#### Static 作用域
当一个函数执行完毕时，它的所有局部变量通常都会被删除。然而，有时候你希望某个局部变量不要被删除。

要做到这一点，可以在第一次声明变量时使用**<font style="color:#DF2A3F;">static</font>**关键字进行修饰

```php
function test(){
  static $x = 0;
  echo $x;
  $x++;
}

test()
test()
test()
test() // 3
```

每次函数调用时，该变量将会保留前一次函数执行后的结果

<font style="background-color:#FBDE28;">该函数还是局部变量</font>

## echo和print
共同点：输出内容

echo、print、print_r的区别：

+ echo   可以输出一个或多个字符串
+ print   只能输出简单类型变量的值，比如int，string
+ print_r  可以输出复杂类型变量的值，如数组、对象

**<font style="background-color:#FBDE28;">提示：</font>**<font style="background-color:#FBDE28;">echo输出的速度比print快，echo是PHP语句，没有返回值，print和print_r是PHP函数，函数有返回值。print返回值是1(int类型)，print_r返回值是true(bool类型)</font>

### echo
echo是一个语句结构，使用的时候可以加括号也可以不加:echo 和 echo()

显示字符串

```php
<?php
echo "<h2>H2标签</h2>";
echo "我要学 PHP!<br>";
echo "这是一个", " 字符串", " 使用了", " 多个", " 参数。";
```

显示变量

```php
<?php
$txt = "学习PHP";

echo $txt;
echo "我在".$txt;
```

### print
print 同样是一个语言结构，可以使用括号：print 或 print()

显示字符串

```php
<?php
print "<h2>PHP 很有趣!</h2>";
print "Hello world!<br>";
print "我要学习 PHP!";
```

显示变量

```php
<?php

print($txt);
print("我在".$txt);
```

## 常量
**<font style="background-color:#FBDE28;">常量被定义后，在脚本的其他任何地方都不能被改变</font>**

常量是一个简单值的标识符。

一个常量由英文字母、下划线和数字组成，但数字不能作为首字母出现（常量名不需要加$修饰符）

**<font style="background-color:#FBDE28;">常量在整个脚本中都可以使用</font>**

### 设置PHP常量
设置常量，使用define()函数，函数语法如下：

```php
bool define(string $name,mixed $value[, bool $case_insensitive=false])
```

该函数有三个参数

+ name：必填参数，常量名称，即标识符。
+ value：必填参数，常量的值。
+ $case_insensitive：可选参数，如果设置为true，那么该常量则大小写不敏感。默认是大小写敏感的。

区分大小写

```php
<?php
define("GREETING","Welcome to w3cschool.cn!");
print(GREETING);
```

不区分大小写的常量（**PHP7.4+已废弃该写法**）

```php
<?php
// 第三个参数为true，该写法在PHP7.4+已被移除
// 可以考虑使用constant()
// define("GREETING", "Welcome to w3cschool.cn!", true);
define("GREETING", "Welcome to w3cschool.cn!");
echo GREETING;
?>
```

### 常量是全局的
```php
<?php

define("GREETING","欢迎");

function test(){
  var_dump(GREETING); // string 欢迎
}
test();
```

## 字符串变量
### 并置运算符
在PHP中只有一个字符串运算符：**并置运算符（.）****<font style="color:#DF2A3F;">用于将两个字符串连接起来</font>**

```php
<?php
$text1 = "hello world";
$text2 = "hello PHP";

// echo $text1 . $text2;
echo $text1." ".$text2;
```

### strlen
strlen()函数返回字符串的长度（字符数）。

```php
<?php
echo strlen("hello world");
```

### strpos
strpos()函数用于在字符串内查找一个字符或一段指定的文本

如果在字符串中找到匹配，那么改函数会返回第一个匹配的字符位置。如果未找到匹配，则返回false

```php
<?php
echo strpos("hello world!","wo"); // 6  字符w 在第一个参数索引为6的位置 索引从0开始
```





## 运算符
PHP中的运算符分为：算术运算符、递增/递减运算符、比较运算符、逻辑运算符、数组运算符、三元运算符等

### 算数运算符
```php
<?php
$x = 10;

echo ($x + $y); // 16
echo ($x - $y); // 4
echo ($x * $y); // 60
echo ($x / $y); // 1.666666

```
