## 变量
### 变量命名规则：
+ 变量名以 $ 符号开始，后面跟着变量名
+ 变量名必须以字母或者下划线字符开始
+ 变量名只能包含字母数字字符下划线
+ 变量名不能有空格
+ 变量名是区分大小写的

> php语句和变量都是区分大小写的
>

```php
<?php
$age = 18;
$name = 'szp'
?>
```



### 变量的作用域：
变量的作用域是脚本中变量可被使用（引用）的部分

PHP有四种不同的变量作用域：

+ lcoal
+ global
+ static
+ parameter

#### 局部和全局作用域（local、global）
> **<font style="color:#DF2A3F;">在所有函数外部定义的变量，拥有全局作用域</font>**
>

除了函数外，全局变量可以被脚本中的任何部分访问，要在一个函数中访问一个全局变量，需要使用global关键字

```php
<?php
// 全局变量
$name = 'szp';

function myTest(){
  global $name; // 声明使用全局变量
  echo $name;

  // 或者通过$GLOBALS超全局数组访问
  echo $GLOBALS['name'];

  // 修改全局变量
  $GLOBALS['name'] = 'Tom';
}
myTest()

echo $name; // Tom
?>
```

<font style="background-color:#FBDE28;">PHP将所有全局变量存储在一个名为$GLOBALS的数组中，这个数组可以在函数内部访问，也可以直接用来更新全局变量的值</font>

在php函数内部声明的变量是局部变量，仅能在函数内部访问：

```php
function myTest(){
  $age = 10; // 局部变量
  echo $age;
}
```

#### Static 作用域
当一个函数执行完毕时，它的所有局部变量通常都会被删除。然而，有时候你希望某个局部变量不要被删除。

要做到这一点，可以在第一次声明变量时使用**<font style="color:#DF2A3F;">static</font>**关键字进行修饰

```php
function test(){
  static $x = 0;
  echo $x;
  $x++;
}

test()
test()
test()
test() // 3
```

每次函数调用时，该变量将会保留前一次函数执行后的结果

<font style="background-color:#FBDE28;">该函数还是局部变量</font>

## 常量
**<font style="background-color:#FBDE28;">常量被定义后，在脚本的其他任何地方都不能被改变</font>**

常量是一个简单值的标识符。

一个常量由英文字母、下划线和数字组成，但数字不能作为首字母出现（常量名不需要加$修饰符）

**<font style="background-color:#FBDE28;">常量在整个脚本中都可以使用</font>**

### 设置PHP常量
设置常量，使用define()函数，函数语法如下：

```php
bool define(string $name,mixed $value[, bool $case_insensitive=false])
```

该函数有三个参数

+ name：必填参数，常量名称，即标识符。
+ value：必填参数，常量的值。
+ $case_insensitive：可选参数，如果设置为true，那么该常量则大小写不敏感。默认是大小写敏感的。

区分大小写

```php
<?php
define("GREETING","Welcome to w3cschool.cn!");
print(GREETING);
```

不区分大小写的常量（**PHP7.4+已废弃该写法**）

```php
<?php
// 第三个参数为true，该写法在PHP7.4+已被移除
// 可以考虑使用constant()
// define("GREETING", "Welcome to w3cschool.cn!", true);
define("GREETING", "Welcome to w3cschool.cn!");
echo GREETING;
?>
```

### 常量是全局的
```php
<?php

  var_dump(GREETING); // string 欢迎
}

### 错误控制运算符
 <font style="color:rgba(0, 0, 0, 0.88);">在 PHP 中，“错误处理运算符”主要指 </font>`**<font style="color:rgba(0, 0, 0, 0.88);background-color:rgba(175, 184, 193, 0.2);">@</font>**`**<font style="color:rgba(0, 0, 0, 0.88);">（错误抑制运算符）</font>**<font style="color:rgba(0, 0, 0, 0.88);">，它是 PHP 特有的单目运算符，用于 </font>**<font style="color:rgba(0, 0, 0, 0.88);">抑制表达式执行过程中产生的错误信息</font>**<font style="color:rgba(0, 0, 0, 0.88);">（不显示错误，但错误仍然存在）。</font>

1. **<font style="color:rgba(0, 0, 0, 0.88);">抑制函数调用错误</font>**<font style="color:rgba(0, 0, 0, 0.88);"> 例如，当文件不存在时，</font>`<font style="color:rgba(0, 0, 0, 0.88);background-color:rgba(175, 184, 193, 0.2);">fopen()</font>`<font style="color:rgba(0, 0, 0, 0.88);"> 会报错，用 </font>`<font style="color:rgba(0, 0, 0, 0.88);background-color:rgba(175, 184, 193, 0.2);">@</font>`<font style="color:rgba(0, 0, 0, 0.88);"> 抑制错误：</font>

```

2. **<font style="color:rgba(0, 0, 0, 0.88);">抑制变量未定义错误</font>**<font style="color:rgba(0, 0, 0, 0.88);"> 访问未定义的变量时，PHP 会报 </font>`<font style="color:rgba(0, 0, 0, 0.88);background-color:rgba(175, 184, 193, 0.2);">Notice: Undefined variable</font>`<font style="color:rgba(0, 0, 0, 0.88);">，用 </font>`<font style="color:rgba(0, 0, 0, 0.88);background-color:rgba(175, 184, 193, 0.2);">@</font>`<font style="color:rgba(0, 0, 0, 0.88);"> 抑制：</font>

...

**<font style="background-color:#FBDE28;">不能抑制所有错误</font>**

@不能抑制以下错误：

+ `E_ERROR` (致命错误、如语法错误、内存溢出)
+ `E_PARSE` （编译时解析错误、如括号不匹配）

+ `E_COMPILE_ERROR`（编译时致命错误）
+ 用户自定义的错误处理函数中抛出的错误（通过`set_error_handler`设置的处理函数）

+ rsort() - 对数组进行降序排序

```php
<?php
$arr = array("b","a","c","f","d");
rsort($arr);

$arr_length = count($arr);

for($x= 0;$x<$arr_length;$x++){
  var_dump($arr[$x]);
}
```

+ asort() - 根据关联数组的值，对数组进行升序排序

```php
<?php
$age=array("Peter"=>"35","Ben"=>"37","Joe"=>"23");
asort($age);
var_dump($age);
```

+ ksort() - 根据关联数组的键，对数组进行升序排序

```php
<?php
$age=array("Peter"=>"35","Ben"=>"37","Joe"=>"43");
ksort($age);
var_dump($age);
?>
```

+ arsort() - 根据关联数组的值，对数组进行降序排序

```php
<?php
$age=array("Peter"=>"35","Ben"=>"37","Joe"=>"23");
arsort($age);
var_dump($age);
```

+ <font style="color:rgb(51, 51, 51);">krsort() - 根据关联数组的键，对数组进行降序排列</font>

```php
<?php
$age=array("Peter"=>"35","Ben"=>"37","Joe"=>"43");
krsort($age);
var_dump($age);
?>
```
